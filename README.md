## Virtual Environment

This project uses `uv` for package and environment management.

### Activating the Virtual Environment

To activate the virtual environment, run the appropriate command for your shell:

**macOS / Linux:**
```bash
source .venv/bin/activate
```

**Windows (PowerShell):**
```powershell
.venv\Scripts\Activate.ps1
```

**Windows (cmd):**
```cmd
.venv\Scripts\activate.bat
```

### Running Commands without Activation

Alternatively, you can run commands directly in the virtual environment without activating it by using `uv run`:

```bash
uv run python script.py
```
